# Asset provenance

The Catch Burger logo, original cheeseburger photograph and restaurant exterior photograph were supplied by the user. The cheeseburger image in `assets/menu/cheeseburger.webp` is cropped from that supplied photograph.

Other menu images and the five hero ingredient cutouts were generated using OpenAI's built-in image-generation tool. They are illustrative and should be replaced with verified restaurant product photography before real ordering.

The live hero uses photographic layers on an HTML canvas. It does not use the older 3D model or Three.js files, which are intentionally excluded from this repository.

The CSS contains a generated SVG grain effect and geometric accents. Fonts are referenced through Google Fonts.

The repository includes the active website files and required image assets. Private hosting manifests, Git credentials, temporary files and earlier draft assets are excluded.
