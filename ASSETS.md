# Asset provenance

The active website uses the user-supplied Catch Burger logo, original cheeseburger photograph and restaurant exterior photograph.

- `assets/menu/cheeseburger.webp`: crop from the supplied original restaurant photograph.
- `assets/catch-exterior.png`: supplied restaurant exterior.
- `assets/logo.png`: supplied branding.

The generated menu images and ingredient cutouts remain in the repository as older assets, but are not displayed by the current menu. The animated burger canvas has been removed from the page.

No generated product photograph is presented as a real restaurant dish. The menu intentionally uses text for items without verified photography. Google Fonts are loaded externally.
